# Roadmap

RepoLens Community Edition is focused on improving the public local analysis engine and the contributor experience around it.

## Short-Term Priorities

These are the main areas we want to improve in the open-source community edition:

- stronger repository scanning and ignore handling for common local project layouts
- broader stack detection coverage for common JavaScript and TypeScript repositories
- richer AST-based extraction for modules, imports, exports, and symbol metadata
- clearer dependency graph output and architecture summaries
- better CLI ergonomics, examples, and contributor documentation
- stronger test coverage for scanners, parsers, graph generation, and API extraction

## Long-Term Direction

Areas we want to keep improving over time:

- broader support for additional local framework patterns that fit the current community scope
- more useful normalized analysis output for automation and developer tooling
- better onboarding-oriented summaries from the extracted core engine
- clearer package boundaries and reusable public contracts
- a smoother open-source contributor experience with better docs and fixtures

## Community Edition Boundaries

This roadmap is only for the public community edition. It covers local repository analysis and supporting developer tooling in this repository.

## Cloud-Only Features

The following are intentionally out of scope for this public roadmap:

- repo chat
- embeddings or vector search
- private repository access
- hosted authentication or GitHub OAuth
- team workspace or collaboration features
- branch comparison
- premium export workflows
- billing, subscriptions, or usage controls tied to a hosted product

## How To Contribute

If you want to work on a roadmap item, open or comment on an issue first when possible so the work stays aligned with the public package boundaries and community-edition scope.
