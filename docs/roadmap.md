# Community Edition Roadmap

## Goal

RepoLens Community Edition provides a local-first repository analysis engine and CLI for understanding application structure without any SaaS dependencies.

## Planned milestones

1. Repository scanning and deterministic file discovery
2. Stack and framework detection from local metadata
3. TypeScript and JavaScript source parsing with reusable extraction contracts
4. Module detection and dependency graph generation
5. API extraction for common local frameworks
6. Architecture and onboarding summaries from normalized analysis data
7. CLI workflows for analyzing local repository paths
8. Examples, tests, and contributor documentation for the public packages

## Explicit non-goals

- Repo chat
- Embeddings or vector search
- Private repository access
- OAuth or hosted account flows
- Team workspace features
- Branch comparison
- Premium report exports
- Billing or subscription logic
